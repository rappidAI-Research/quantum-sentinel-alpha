# Security reporting

For a vulnerability in Sentinel's code, evaluation harness or data pipeline,
email [cikemgil@rappidai-research.com](mailto:cikemgil@rappidai-research.com).
Include the affected revision, impact and a minimal reproduction without
credentials, private code or restricted training material. Do not disclose
sensitive reports in a public issue. No response time is guaranteed.

Sentinel is experimental and has no released model or validated security
performance. Review generated findings and patches independently. Read the
[threat model](docs/THREAT_MODEL.md), [coding-sandbox contract](docs/CODING_SANDBOX.md)
and [data-governance rules](docs/DATA_GOVERNANCE.md) before running workloads.
